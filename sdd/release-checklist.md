# Release Checklist

- [ ] Production build and Node 24 Docker runtime pass.
- [ ] Dashboard, comparison, detail, filters, and navigation pass Playwright.
- [ ] Desktop and mobile screenshots are reviewed.
- [ ] Unit tests prove domain/application behavior without framework or network.
- [ ] Benchmark result validates against V2 and comes from a clean source commit.
- [ ] README opens with project number, claim, result, and one Docker path.
- [ ] `REFERENCES.md` records dependencies, inspiration, and licenses.
- [ ] Default mode needs no secret or external service.
- [ ] Reuse review is complete.
- [ ] GitHub Actions is green on the published SHA.
